# أوقات الصلاة – الكويت

تطبيق iPhone لأوقات الصلاة في الكويت مع أوقات الإقامة لكل مسجد وويدجت.

## البناء
1. أنشئ ريبو جديد على GitHub وارفع كل الملفات (بما فيها مجلد `.github`).
2. من تبويب Actions شغّل **Build IPA** (أو يشتغل تلقائياً مع أول push).
3. حمّل الـ artifact باسم `KuwaitSalah-ipa` وفك الضغط لتحصل على `KuwaitSalah.ipa`.
4. ثبّته بـ Sideloadly.

## الإقامة
تضبط الدقائق بعد الأذان لكل صلاة من الإعدادات. الويدجت يستخدم القيم الافتراضية في `Shared/Iqama.swift`.

## ملاحظات
- الحساب فلكي بدون إنترنت: فجر ١٨° وعشاء ١٧٫٥° (طريقة الكويت). عدّل الدقائق من الإعدادات إن اختلف عن تقويم الأوقاف.
- الويدجت لا يقرأ إعدادات التطبيق لأن الحساب المجاني لا يدعم App Groups.
